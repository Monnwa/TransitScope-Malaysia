# HCI principles and standards

TransitScope follows an iterative, human-centred approach consistent with ISO 9241-210:2019. It evaluates effectiveness, efficiency and satisfaction through the planned study in line with ISO 9241-11:2018.

| Principle | Interface evidence |
| --- | --- |
| Visibility of system status | Live status message, SIMULATED badge, timestamps and result count. |
| Feedback | Search, filters, marker selection and alert opening announce their result. |
| Consistency and standards | Shared terminology, filter behaviour, colours and panel structure. |
| Affordances and signifiers | Buttons, pressed states, links and map markers look actionable. |
| User control and freedom | Reset dashboard, clear search and close alert controls. |
| Error prevention and recovery | Explicit unavailable data and a recovery path from empty results. |
| Cognitive load and hierarchy | KPIs precede map and table, with detail on selection. |

## Accessibility inspection scope

The implementation includes semantic headings, table headers, accessible control names, visible focus rings, a skip link, polite status feedback and an alternative map list. This is an inspection against relevant WCAG 2.2 ideas, not a claim of full conformance.

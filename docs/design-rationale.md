# Design rationale

The dashboard uses a left navigation rail for stable destinations and a top-level global search for the primary commuter task. KPIs give an immediate summary before users invest attention in the map. Filters apply to every evidence view so the counts, chart, table and map do not conflict. A map marker opens the same detail vocabulary used in the table, while the table supplies an accessible non-map alternative.

Colour distinguishes modes, but text labels and legend entries carry the same meaning. Data mode is always textual. SIMULATED and SCHEDULED values never imply an actual live vehicle position. Rail records model stations only because this demonstration has no verified rail vehicle feed.

The implemented improvement is a persistent source-transparency section and status message. It prevents the most serious anticipated misunderstanding: treating classroom data as travel advice. Its effectiveness requires participant validation.

# Project limitations

- This release contains deterministic fictional demonstration records, not real vehicle tracking or journey advice.
- No verified Malaysian operator GTFS, GTFS-Realtime or GBFS endpoint is connected.
- Rail entries represent station and route references, not fabricated train locations.
- Historical availability charts are omitted because no historical dataset exists.
- User research results, task metrics and SUS scores are pending participant testing.
- Public deployment and recorded-presentation links are pending user action.

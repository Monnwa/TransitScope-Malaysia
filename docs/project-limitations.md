# Project limitations

- LIVE vehicle records depend on current availability of the Malaysia Official Open API. Network or upstream failures show as UNAVAILABLE or STALE.
- Demonstration records remain fictional and appear only after the user explicitly switches to demonstration mode.
- Rapid KL Rail entries use published GTFS Static station information because the official documentation does not identify a stable realtime rail feed.
- No verified accessible Malaysian GBFS feed was identified, so shared-bike availability remains unavailable.
- Historical availability charts are omitted because no historical dataset exists.
- User research results, task metrics and SUS scores are pending participant testing.
- Public deployment and recorded-presentation links are pending user action.
